# mend

One patch tool for every AI edit format: unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON tool calls, applied atomically to a tree of text files.

Built for [Build mend on make.fun](https://make.fun/bounty/hidden-spec-cli-01-run-20261122).
